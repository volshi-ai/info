# Security Policy

## Reporting a Security Issue

Please do not disclose suspected vulnerabilities publicly through repository issues, discussions, social media, or other public channels.

If you believe you have identified a security issue affecting ARCHE or a VOLSHi-controlled ARCHE surface, contact VOLSHi privately through an official contact channel.

Where practical, include:

- the affected product or surface;
- a clear description of the observed behavior;
- reproduction steps;
- the potential impact; and
- relevant logs or screenshots with credentials and sensitive information removed.

## Sensitive Information

Do not include passwords, API keys, access tokens, private customer information, private repository contents, proprietary implementation material, or other credentials in a report unless a secure exchange method has been established.

## Scope of This Repository

`ARCHE-info` is a public information repository. It does not contain the private ARCHE source code or proprietary implementation.

## Disclosure

Please allow reasonable time for investigation and remediation before public disclosure.
