ERIE

Epistemic Retrieval and Investigation Engine. Every answer cited to the record, or no answer at all.

What ERIE does

  • Deterministic, model-free retrieval over a connected corpus. No model sits in the retrieval path, so the same question gets the same answer every time.
  • Every answer is cited to record entries with a KID, a birth stamp, and a trust grade. You can check where every part of an answer came from.
  • It says cannot-answer when the record does not support an answer. It never guesses to fill a gap.
  • It kills hallucinations on a connected corpus. Nothing reaches the answer that is not in the record.

How it differs from RAG

RAG retrieves passages, dumps them in the prompt, and asks the model to build an answer. ERIE hands the model the ingredients and the recipe: the facts, cited and trust-graded, plus how to use them.

See the difference yourself. One chat input goes to both RAG and ERIE, with an inspection terminal to compare their outputs.
